## Root cause — the prerender snapshot

`scripts/prerender.cjs` captures each page at the first animation frame. What crawlers / AI see:
- Homepage stats read "0+ Clients delivered", "0-day", "0-stage" (verified).
- Hero paragraph ships at `opacity:0` — it is the mobile LCP element.
- Split-word headlines extract as "Websitesthatconvertbuiltindays,notmonths." (headline component).
- GTM loader injected twice; frozen mid-animation transforms; `lenis` class on `<html>`.

## Findings

### Critical
1. Homepage stats prerender as zero.
2. Ameli described as "a skin and brow studio" in the /work/cw-electronics next-project teaser
   (she's a graphic designer).

### High
3. Facts disagree across pages/schema: turnaround 3–7 days vs 3–5 working days; FAQ package names
   not used on /hosting; schema priceRange; opening hours (Mon–Fri 8–5 vs schema Saturday).
   → single facts source.
4. Town names (Vanderbijlpark / Vereeniging / Sasolburg) only in schema; homepage H1 is sr-only and
   keyword-free.
5. No visible reviews / testimonials; GBP not linked from site.
6. Thin service pages (/websites 162 words, /systems 241, /hosting 253).
7. three.js (vendor-three ~227KB br) modulepreloaded on every route; GTM ~530ms TBT on mobile.

### Medium
- Schema: founder Person is a bare name; areaServed typed `City` for Gauteng/South Africa; no
  ContactPage/AboutPage/CollectionPage; unused builders in `src/lib/structured-data.ts`.
- No `tel:` links anywhere (verified).
- Intent: /systems vs booking-software SERPs; /restaurant-direct never says "commission";
  cost-guide content gap.
- Images: /work/blom hero 2000px/347KB lazy + no srcset; 59/61 images without width/height.
- Titles >60 chars: /restaurant-direct 87, /websites 70, / 67. All pages share one og-image.
- Sitemap lastmod = build date for every URL.
- Render-blocking Google Fonts CSS.

### Low
- Contact form button is `type="button"` (no native submit); honeypot label readable by agents.
- /index.html 200 (no redirect); webmanifest served as octet-stream; 404 canonical `/__not_found__`;
  /lab both robots-disallowed and noindex; nav labels duplicated in extracted text.
- Live CSP differs from netlify.toml (uncommitted local change at audit time).
- Old `streamline-sigma.vercel.app` still indexed (HTTP 402).
- Ameli / JJ Glass have no footer credit back.

## Fixes applied — 2026-11-12 (uncommitted at time of writing)

Verified on a local production build (`npm run build`, prerender 16/16).

- **Prerender snapshot** (`scripts/prerender.cjs`): snapshots taken with `prefers-reduced-motion: reduce`
  and cleaned — stats read 8+ / 700+ / 4-day / 12-stage, no parked `opacity:0` content (decorative
  aria-hidden layers left alone), injected GTM `<script src>` stripped, `lenis` html class removed,
  async font stylesheet reset to `media="print"`.
- **Headlines** (`SplitReveal.tsx`): real space text nodes between words → "Websites that convert…".
- **Facts**: `TURNAROUND` = 3–5 working days used everywhere; FAQ + /hosting meta no longer use the
  retired package names; contact hours copy from `CONTACT.replyHours`; Ameli teaser fixed.
- **Contact form**: native `type="submit"`, honeypot label de-inviting, pill rows are labelled groups,
  `tel:` link added.
- **Schema**: Person `#christiaan` (founder), GBP in `sameAs` + `hasMap`, CIPC identifier, contactPoint,
  areaServed types fixed, priceRange "From R699/month"; AboutPage / ContactPage / CollectionPage nodes;
  unused builders removed.
- **On-page**: titles ≤62 chars incl. brand; homepage H1 + eyebrow carry "Vaal Triangle"; /websites names
  Vanderbijlpark, Vereeniging, Sasolburg; per-case-study og images (`public/og/work-*.jpg`); no canonical
  on 404; robots.txt no longer disallows /lab (noindex is readable).
- **Sitemap**: lastmod from git history per page; changefreq/priority dropped.
- **Performance**: vite preload helper split out of `vendor-three` (three.js no longer modulepreloaded on
  every route); pre-footer 3D scene mounts only near viewport; Google Fonts CSS non-blocking; case-study
  heroes eager + `fetchpriority=high` + srcset (640/1000) + width/height.
- `site.webmanifest` served as `application/manifest+json`.

Lighthouse 12.8.2 mobile, same local server, baseline (HEAD) → new:
/ 61 → 75 · /websites 51 → 60 · /work/blom 53 → 67 (sim. LCP 12.3s → 5.3s on BLOM).
